# Giftmint — legal & support

Published source for the Giftmint iPhone app's **Terms of Use**, **Privacy Policy** and **support**
page, served with GitHub Pages:

- Support — https://ganeshrajugalla.github.io/Giftmint-legal/
- Privacy Policy — https://ganeshrajugalla.github.io/Giftmint-legal/privacy/
- Terms of Use — https://ganeshrajugalla.github.io/Giftmint-legal/terms/

Static HTML only: no JavaScript, no cookies, no analytics, no external fonts. The canonical copies are
kept with the app's source; this repository mirrors them so App Review can reach them without an
account.
